# Sol scenario fixture

These JSON files preserve the former automatic Sol and Earth startup world, including its empires and corporations. The normal application now starts with an empty world and does not load this fixture. `SpaceConquestEngine.fromSolScenario()` loads it explicitly for tests and for possible future scenario development.

This fixture is separate from galaxies created by the New game flow. It is not currently offered as a selectable campaign in the game menu.
