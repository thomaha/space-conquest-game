# Production coverage and remaining gaps

All research, installed equipment, site access, discovered declared deposits, power, workers and cash are assumed for graph closure. A graph path is not proof of funded construction, resource discovery or profitable campaign operation. Every catalog recipe also runs through the physical market-settlement test in ProductionChainAuditTest. Separate command lifecycle tests cover research, material-funded construction, reload and actual delivered products.
